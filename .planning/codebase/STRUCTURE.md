## Directory Purposes

**src/main:**
- Purpose: Electron main process — database, IPC, AI integration
- Contains: Database client, schema, IPC handlers, AI model clients, security utilities
- Key files: `index.ts` (entry point), `db/client.ts`, `ipc/*.ts`, `ai/router.ts`

**src/main/ai:**
- Purpose: AI model integration and task routing
- Contains: Model client wrappers, cost calculation, usage logging, task router
- Key files: `router.ts` (task→model mapping), `types.ts` (ModelResponse interface), `*-*.ts` (model clients)

**src/main/db:**
- Purpose: Database initialization and schema
- Contains: SQLite client setup, Drizzle schema definitions, migrations
- Key files: `client.ts` (initDb/getDb), `schema.ts` (5 tables)

**src/main/ipc:**
- Purpose: IPC endpoint handlers for projects, settings, and AI
- Contains: Request handlers, validation, rate limiting, audit logging
- Key files: `projects.ts`, `settings.ts`, `ai.ts`, `security.ts` (shared utilities)

**src/preload:**
- Purpose: Secure bridge exposing typed API to renderer
- Contains: Context bridge setup, type definitions for IPC channels
- Key files: `index.ts` (bridge), `index.d.ts` (TypeScript types)

**src/renderer/src:**
- Purpose: React frontend application
- Contains: Pages, components, state stores, utilities

**src/renderer/src/components:**
- Purpose: Reusable UI components organized by feature
- Contains: Layout wrappers, usage visualization, model display, primitives
- Organization: layout/, usage/, models/, project/, ui/

**src/renderer/src/pages:**
- Purpose: Route-level page components
- Contains: Home (project list), Project (detail), Settings (API keys), Models (usage analytics)

**src/renderer/src/lib:**
- Purpose: Application utilities, state, constants
- Contains: Zustand stores (projects), formatting functions, constants (model metadata)

## Key File Locations

**Entry Points:**
- `src/main/index.ts`: Electron main process — creates window, initializes DB, registers IPC
- `src/preload/index.ts`: Preload script — exposes ForgeApi via context bridge
- `src/renderer/src/main.tsx`: React root — mounts App component
- `src/renderer/src/App.tsx`: React router and layout

**Configuration:**
- `package.json`: Scripts (dev, build, preview, package), dependencies
- `electron.vite.config.ts`: Build config for main/preload/renderer
- `drizzle.config.ts`: Database migration output directory
- `tsconfig.json`: TypeScript compiler options

**Core Logic:**
- `src/main/ai/router.ts`: Task type → model selection
- `src/main/ipc/ai.ts`: AI call handler, usage aggregation
- `src/main/db/schema.ts`: Database schema (projects, modelUsage, etc.)
- `src/renderer/src/lib/stores/projects.ts`: Project state management

**Testing:**
- Not yet implemented (no test files found)

## Naming Conventions

**Files:**
- Main process files: `camelCase.ts` (e.g., `index.ts`, `client.ts`, `router.ts`)
- React components: `PascalCase.tsx` (e.g., `Home.tsx`, `Header.tsx`, `UsageCard.tsx`)
- Type definitions: `index.d.ts` for exported types
- Store modules: named by domain (e.g., `projects.ts` for projects store)

**Directories:**
- Feature-based: `ai/`, `db/`, `ipc/` (main); `pages/`, `components/`, `lib/` (renderer)
- Lowercase kebab-case-like but with slashes: `src/main/`, `src/renderer/src/`

**Functions:**
- Handlers: `register*Ipc`, `handle*` (e.g., `registerProjectsIpc`, `handleAiCall`)
- Utilities: `*` with clear intent (e.g., `formatCost`, `initDb`, `routeTask`)
- Components: `use*` for hooks (e.g., `useProjectsStore`), `*` for components

**Variables/Types:**
- camelCase for variables and functions
- PascalCase for types and interfaces (e.g., `ProjectRow`, `ModelResponse`, `TaskType`)
- UPPERCASE for constants (e.g., `MAX_NAME_LENGTH`, `VALID_KEYS`)

**IPC Channels:**
- Kebab-case with colons: `projects:create`, `settings:get`, `ai:call`, `ai:usage-summary`

## Where to Add New Code

**New Feature (e.g., new project type):**
- Primary code: `src/main/ipc/` (IPC handler), `src/main/db/schema.ts` (if schema change)
- Frontend: `src/renderer/src/pages/` (new page) or `src/renderer/src/components/` (components)
- Types: `src/preload/index.d.ts` (if exposing new API)

**New Component/Module:**
- Layout/UI component: `src/renderer/src/components/{feature}/Component.tsx`
- Page component: `src/renderer/src/pages/PageName.tsx`
- Main process module: `src/main/{feature}/module.ts`
- Store: `src/renderer/src/lib/stores/featureName.ts`

**Utilities:**
- Shared helpers (formatting, constants): `src/renderer/src/lib/`
- Database queries: Add handlers in `src/main/ipc/`
- AI integration: Extend `src/main/ai/` modules
- Security/validation: Add to `src/main/ipc/security.ts`

**New Database Table:**
1. Add table definition to `src/main/db/schema.ts`
2. Run `npx drizzle-kit generate` to create migration
3. Queries auto-generated by Drizzle; use `getDb()` to access
4. Expose via IPC handler in `src/main/ipc/`

## Special Directories

**src/main/db/migrations/:**
- Purpose: Generated SQL migrations
- Generated: Yes (by drizzle-kit)
- Committed: Yes
- Contents: Numbered .sql files + meta.json tracking applied migrations

**src/main/ai/prompts/:**
- Purpose: System prompts for each AI task type
- Generated: No
- Committed: Yes
- Contents: Prompt templates for intake, planning, codegen, review, security, testing, deploy

**out/:**
- Purpose: Compiled output (main/preload/renderer bundles)
- Generated: Yes (by electron-vite during build)
- Committed: No (in .gitignore)

**dist/:**
- Purpose: Packaged app (created by electron-builder)
- Generated: Yes (by electron-builder after vite build)
- Committed: No (in .gitignore)

**node_modules/:**
- Purpose: Installed dependencies
- Generated: Yes (by npm install)
- Committed: No (in .gitignore)

## Import Aliases

- `@renderer`: Maps to `src/renderer/src` (for renderer imports)
- `@`: Alternate alias for `@renderer`
- No aliases for main process (use relative imports)
